# Conveyor plain-English profile

Citation scope: the REQ, AC, DEC, and component IDs in this guidance, and its
other requirement, design, and reference IDs, cite the Conveyor product's own
design corpus, not the corpus of the factory you work in. Task work cites the
working factory's own confirmed corpus, as the delivered contract directs.

Read and follow
[docs/playbooks/conveyor-plain-english.md](../../../docs/playbooks/conveyor-plain-english.md).
It holds the profile rules, the exemptions, the glossary, the examples, and
the check list.

Non-negotiables, restated:

- Apply the profile to new and changed text only.
- Never change code, identifiers, commands, paths, quoted text, or official
  names.
- Treat a profile finding as advice. No gate, CI job, or validator fails on a
  profile finding alone.
- Keep the first-sentence rules for timeline text in full.

Keep this wrapper thin. The playbook holds the canonical guidance.
